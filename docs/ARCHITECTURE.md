# Exercise Engine Architecture — Prototype 1

هذه النسخة مستقلة عن خط v4/v4.1، والغرض منها اختبار منطق الأنشطة قبل إنتاج واجهات المنصات.

## الطبقات

1. **Arabic Core**: تحليل الحروف والحركات والاتصال والسياق.
2. **Exercise Engine**: تعريف الهدف، ترتيب الوحدات، المقارنة، المحاولات، والتغذية الراجعة.
3. **Magnetic Board Adapter**: تحويل وحدات النشاط إلى قطع فوم مستقلة، إدارة مناطق التركيب والخانات والسحب.
4. **Platform Profiles**:
   - iOS PWA: touch-first + safe areas + long press.
   - Android PWA: touch-first + أحجام شاشات متعددة.
   - webOS TV PWA: focus-first + D-pad/OK بدل السحب اللمسي.

## أوضاع السبورة

- **حر**: كل قطعة مستقلة، ولا توجد إجابة صحيحة مفروضة.
- **كوّن كلمة**: كلمة هدف + حروف منثورة مستقلة + خانات RTL + تحقق.
- **كلمات مكتملة**: الكلمات الجاهزة تبقى مجموعات يمكن نقلها ثم فكها أو إعادة تجميعها.

## مبدأ مهم

في وضع «كوّن كلمة» لا تُستخدم `wordId` لربط القطع مسبقًا. كل حرف قطعة مستقلة، ويحمل فقط بيانات النشاط (`exerciseId`, `exerciseUnit`, `exerciseSlot`). لذلك يستطيع الطالب ترتيب الحروف بحرية، بينما يعرف المحرك الإجابة دون فرض موضع الحرف قبل السحب.
