# Arabic Language Lab — Exercise Engine Prototype v1

نسخة مستقلة لتجربة محرك الأنشطة التعليمية للسبورة العربية، دون التأثير على النسخة المرجعية الحالية.

## أوضاع السبورة
- **الوضع الحر:** كل حرف قطعة مستقلة.
- **كوّن كلمة:** نثر الحروف وترتيبها داخل خانات RTL مع التحقق والتلميح وإعادة النثر.
- **كلمات مكتملة:** نقل الكلمة كمجموعة مع إمكانية فكها وإعادة تجميعها.
